# 🌸网易云·青樱🎵

版本：1.2｜平台：网页端｜开源协议：MIT｜AI模型：GLM-4-Flash

**樱花主题网页音乐播放器**
听歌、滚动歌词、全网榜单、AI点歌一体化音乐工具

---

## 🌈功能特色
### 🎵音乐播放
支持歌曲、歌手、关键词检索曲目。配备完整播放控制：播放暂停、切歌、进度拖拽。
三种播放模式自由切换，0.5倍至2倍播放调速，附带定时自动关闭功能，可选15/30/60/90分钟。

### 📻全网音乐排行榜
收录各类热门榜单：国内热歌、飙升新歌、原创民谣电音，同时包含ACG二次元、抖音热歌、中文说唱与欧美Billboard公告榜单。

### 🎤智能歌词系统
歌词跟随歌曲进度逐行高亮滚动，点击歌词即可跳转播放位置。支持放大缩小文字，内置调色工具，十多种预设颜色外加自定义取色，随心修改歌词色彩。

### 🤖青樱AI智能点歌
使用自然语言对话点歌，直接口语描述想听的音乐。可限定在热门榜单内筛选歌曲，AI以卡片形式返回歌曲封面信息，一次推荐3至5首。对话记忆持续保留，能够连续交流推荐歌曲，搭载原生function calling能力，精准读懂你的指令。

### ❤️收藏与播放记录
喜欢的歌曲一键加入收藏。自动记录最近播放曲目，本地保存搜索记录，播放队列可以手动增删调整，自由管理歌单。

### 👤用户系统
QQ快捷登录，登录后自动获取你的头像与昵称。支持自定义主页顶部横幅背景，随时修改个人资料。

## 🎨界面设计亮点
整体采用干净简约白底风格，圆角卡片搭配柔和阴影，视觉清爽不伤眼。
背景图片每5秒自动切换高清4K画面。悬浮迷你播放器，环形进度条展示播放状态。
主题配色选用蓝紫渐变，搭配樱花粉点缀。AI聊天界面模仿微信气泡样式，歌曲附带封面卡片。
完整移动端适配，兼容手机底部安全区域。

---

## 🛠技术实现
前端采用HTML+CSS+原生JavaScript，无需框架，不用复杂打包构建。
音源依托Meting公开协议接口获取网易云音乐资源。
AI功能基于智谱GLM glm-4-flash免费模型，原生function calling。
所有用户数据使用localStorage本地存储，信息保存在设备本地。
兼容现代浏览器与安卓WebView，可以打包编译成安卓APK安装使用。

项目 | 详情
---- | ----
前端 | 原生HTML、CSS、JS，无第三方框架
音源来源 | Meting协议，网易云音乐数据源
AI能力 | 智谱GLM glm-4-flash，原生function calling
存储方式 | localStorage本地存储
运行环境 | 现代浏览器、安卓WebView，支持打包APK
